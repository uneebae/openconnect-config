## 🚨 Emergency Contacts

**If something breaks in production:**

1. **Check logs first:**
   ```sql
   SELECT TOP 20 * FROM transactions_log 
   WHERE status = 'FAILED' ORDER BY id DESC;
   ```

2. **Have rollback ready:**
   - See TROUBLESHOOTING_GUIDE.md "Rollback" section
   - Can revert in <5 minutes

3. **Contact Ethswitch support:**
   - Provide: correlation_id from transactions_log
   - Provide: mpay_resp from transactions_log_req_resp
   - Provide: Your ws_config.id and ws_endpoint_config.id
